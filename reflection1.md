# Рефлексия по практической работе № 1

Во время практической работы я познакомился с системой контроля версий Git, научился работать с ветками и коммитами, а также отправлять HTTP-запросы к OMDb API с помощью Python. Лучше всего у меня получилось разобраться с созданием веток и их использованием для разработки разных версий программы. Основные трудности возникли при настройке SSH-подключения к GitHub, поиске установленного интерпретатора Python и работе с API-ключом, но постепенно мне удалось решить эти проблемы. Я понял, что в основной ветке `main` хранится стабильная версия проекта, а дополнительные ветки позволяют разрабатывать и проверять изменения отдельно. Коммиты нужны для сохранения истории проекта, поэтому важно создавать их после завершения отдельных этапов работы. Также я научился создавать виртуальное окружение `.venv`, которое позволяет устанавливать необходимые библиотеки отдельно от других Python-проектов. Я узнал, что файл `.env` используется для хранения переменных окружения, а API-ключи нельзя записывать непосредственно в код или публиковать на GitHub из соображений безопасности. Ещё я разобрался с форматом JSON, который позволяет передавать структурированные данные и получать из ответа сервиса нужную информацию о фильме. Особенно полезным оказался практический запуск программы, когда мне удалось получить реальные данные о фильме Interstellar через OMDb API. Интерфейс VS Code помогал отслеживать изменения файлов, переключаться между ветками и запускать Jupyter Notebook. AI-ассистент GigaCode помог написать и проверить код, найти возможные ошибки и организовать работу с GitHub. Если бы я выполнял эту работу ещё раз, то заранее проверил бы настройки Python и SSH, а также уделил больше внимания самостоятельному изучению Git-команд, чтобы лучше понимать происходящие процессы.
